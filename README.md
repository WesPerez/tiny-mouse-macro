# TinyMouseMacro · 多屏切换与键鼠录制

给常用位置设置快捷键，一键切换屏幕；也可以录制鼠标、键盘操作和操作间隔，再按顺序回放。

## 日常使用

1. 选择或新建方案，在上方设置快捷键并勾选“启用”。
2. 在显示器地图上选择位置，或点“3 秒后取点”后把鼠标放到目标上。选中已有步骤时，地图会更新这一步的位置。
3. 按方案快捷键运行。需要录制时点“录制操作”，倒计时结束后开始；勾选“录制键盘”可一起记录按键。

更改自动保存。`Ctrl+S` 可立即保存。`Ctrl+Alt+F10` 停止正在进行的操作或录制；`Ctrl+Alt+P` 暂停／恢复自动运行。关闭主窗口后程序留在托盘，托盘菜单可以退出或设置开机启动。

录制内容追加到当前方案，保留操作间隔。双击步骤编辑，拖动排序。“添加动作”可补充组合键、输入文本、拖拽等。“重复与定时”设置次数、速度、定时和指定窗口，不影响主工作区。

连续切换屏幕时，只保留最后选择的位置，不积攒点击。多步操作不会自动排队。录制暂不保留按住时长与连续拖拽轨迹；拖拽请用专门的拖拽动作。

## 按了快捷键却没有反应

在“更多 → 运行记录”查看收到的快捷键和运行结果。“查看详细日志”供排查具体原因。“测试快捷键”期间不运行操作，关闭运行记录后自动恢复。

全局快捷键和跨窗口操作自动启用，不需要逐个设置 VMware、UU 远程等兼容开关。鼠标位置使用宿主机屏幕坐标；远程画面内的操作由远程软件转发。

这仍是 Windows 用户态程序。USB 键盘直通、独占输入、安全桌面或拒绝模拟输入的应用，不能保证可控。收到快捷键、鼠标到位与远端接受按键是不同环节，需按实际结果验收。

## 可选：通过 iCUE 启动方案

“更多 → 运行记录 → 高级工具”保留外部启动器功能。生成方案启动器后，可在 iCUE 中分配到“启动应用”；主程序需保持运行，并开启外部启动器入口。日常快捷键不需要这项功能。

入口只接受已启用的一步移动／左键点击方案，不支持循环或任意命令。iCUE 的普通宏可用不代表它的“启动应用”在虚拟机里也一定可用。

## 数据与发布

- 方案：`%APPDATA%\TinyMouseMacro\macros.json`。旧版方案和坐标兼容。
- 偏好：同目录的 `preferences.json`。
- 详细日志：同目录的 `activity.log`，约 128 KB 后轮转，最多保留两份。不记录普通打字内容。
- 保存使用原子替换，首次改写前保留 `macros.json.backup`。
- 发布命令：`./build-release.ps1`。

脚本先编译和离线检查，再停止原安装路径下的运行实例，覆盖主程序、配套启动器和 `TinyMouseMacro.README.md`。本机原安装位置为 `C:\Users\Wes\Desktop\TinyMouseMacro.exe`，与开机启动一致。发布后核对哈希，临时文件移入回收站，保留方案和自启项。不自动重启或弹 UAC；若当前实例以管理员权限运行，发布也需同等权限。协作约束见 [AGENTS.md](AGENTS.md)。

## 开发与验证

`--self-test` 使用模拟输入环境，不显示窗口、不注册全局热键、不安装监听、不向桌面注入键鼠。包含格式兼容、时间间隔、焦点失败、落点回弹、取消释放、连续切屏和离屏界面检查，不能替代实际 VMware / UU 测试。

回放使用带标记的 `SendInput`，鼠标移动采用虚拟桌面绝对坐标；按下鼠标按钮的同一个输入包包含位置，避免移动与点击使用两套坐标状态。键盘采用扫描码，文本采用 Unicode。远端是否接受输入仍取决于对应应用。

点击前确认位置。前台申请被拒时允许由方案本身的一次点击激活窗口；不会追加试探点击或 Ctrl+Alt。离开远程窗口后检查位置回弹，仅校正移动，再执行后续按键。失败会停止并记录。双击在两下结束后做位置校正，避免打断双击间隔。命名窗口与拖拽要求先获得目标焦点。

详细日志区分触发、置前请求、定位、点击后落点、排队和失败。后续按键核对目标窗口；取消会释放本程序已按下的键和鼠标按钮。后台输入无法拦截已经传给远端的同一按键，请避免与远端常用操作冲突。
